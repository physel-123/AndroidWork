## 社交数据迁移后端（post/comment/like/folk投稿，打卡收藏留本地）

用户决策：打卡（check_in）和收藏（favorite）不迁移，其余（动态/评论/点赞/民俗投稿）全迁后端。

- entities.py：新增 Post / Comment / LikeRecord / FolkCustom 四张表（时间戳用 BigInteger 毫秒，踩坑：PostgreSQL Integer=int32 放不下 13 位毫秒）
- services/social_service.py：动态/评论/点赞/民俗投稿全套 CRUD + 幂等点赞 + 冗余计数
- routers/social.py：/api/social/* 接口（posts/comments/like/folk_customs/member_count）
- seed_service.py：seed_demo_social 播种 5 条演示动态 + 点赞 + 评论（幂等）
- main.py：注册 social 路由 + lifespan 播种社交数据
