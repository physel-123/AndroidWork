# 项目文件总览

> 打开工程后建议按这个顺序看代码，便于快速理解整个项目。

## 一、构建与配置文件

| 文件                       | 说明                                                     |
| -------------------------- | -------------------------------------------------------- |
| `settings.gradle.kts`    | 工程名、模块声明、仓库配置                               |
| `build.gradle.kts`       | 插件版本（AGP 9.2.1 / KSP 2.3.12 / Compose 插件 2.2.10） |
| `app/build.gradle.kts`   | 模块配置：compileSdk 36、minSdk 26、依赖清单             |
| `gradle.properties`      | 构建 JDK、内存、AndroidX 开关                            |
| `local.properties`       | 本机 Android SDK 路径（**不要提交到版本库**）      |
| `app/proguard-rules.pro` | 混淆规则                                                 |
| `.gitignore`             | 版本库忽略规则                                           |

## 二、应用源码（`app/src/main/java/com/example/jieqi/`）

### 1. 入口

| 文件                | 职责                                            |
| ------------------- | ----------------------------------------------- |
| `JieQiApp.kt`     | Application，创建全局 `AppContainer`          |
| `MainActivity.kt` | 唯一的 Activity，Compose 导航宿主，通知权限申请 |

### 2. 领域层（纯 Kotlin，无 Android 依赖，可直接单元测试）

| 文件                              | 职责                                                                       |
| --------------------------------- | -------------------------------------------------------------------------- |
| `domain/SolarTermCalculator.kt` | **核心算法**：VSOP87D 太阳视黄经计算、牛顿迭代求节气时刻、儒略日换算 |
| `domain/TermDateUtils.kt`       | 当前节气 / 下一节气 / 倒计时 / 年度节气表（按年缓存）                      |
| `domain/CheckInCalculator.kt`   | 连续打卡天数、最长纪录、传习等级、月历排版（纯函数）                       |

### 3. 数据层

| 文件                                    | 职责                                                         |
| --------------------------------------- | ------------------------------------------------------------ |
| `data/AppContainer.kt`                | 轻量依赖容器，持有数据库与各仓库                             |
| `data/SettingsStore.kt`               | DataStore：提醒开关/时间、昵称、主题模式                     |
| `data/Repositories.kt`                | 打卡仓库、收藏仓库                                           |
| `data/FolkCustomRepository.kt`        | 民俗仓库：内置数据播种、筛选查询、用户投稿                   |
| `data/db/Entities.kt`                 | Room 实体：CheckInEntity / FavoriteEntity / FolkCustomEntity |
| `data/db/Daos.kt`                     | Room DAO 接口（Flow 响应式查询）                             |
| `data/db/JieQiDatabase.kt`            | Room 数据库单例                                              |
| `data/content/SolarTermContent.kt`    | 24 节气完整内容库（三候/习俗/食俗/养生/诗话/关键词）         |
| `data/content/FolkCustomContent.kt`   | 34 条各地民俗内置数据（含经纬度）                            |
| `data/content/DailyContentFactory.kt` | 每日一句/一俗/一食、分享文案生成                             |

### 4. 通知

| 文件                                | 职责                                    |
| ----------------------------------- | --------------------------------------- |
| `notify/ReminderScheduler.kt`     | AlarmManager 每日提醒调度、通知渠道创建 |
| `notify/DailyReminderReceiver.kt` | 闹钟接收器（发通知）+ 开机恢复接收器    |

### 5. 界面层

| 文件                               | 职责                                                   |
| ---------------------------------- | ------------------------------------------------------ |
| `ui/LocalProviders.kt`           | CompositionLocal：依赖容器、Snackbar                   |
| `ui/theme/Color.kt`              | 国风配色 + 24 节气主题色                               |
| `ui/theme/Type.kt`               | 字体排版（节气名用衬线字体）                           |
| `ui/theme/Theme.kt`              | Material 3 主题（浅色/深色）                           |
| `ui/navigation/Navigation.kt`    | 路由表 + 底部导航栏                                    |
| `ui/components/Components.kt`    | 通用组件：卡片、渐变卡、印章、标签、进度条、统计格     |
| `ui/components/TermWheel.kt`     | **节气罗盘**（Canvas 自绘 + 点击命中）           |
| `ui/components/FolkMapCanvas.kt` | **中国地图**（Canvas 自绘 + 经纬度投影 + 打点）  |
| `ui/screens/HomeScreen.kt`       | 首页：当前节气、倒计时、打卡、今日一俗、足迹           |
| `ui/screens/TermListScreen.kt`   | 节气列表：罗盘、四季筛选、搜索、收藏模式               |
| `ui/screens/TermDetailScreen.kt` | 节气详情：由来、三候、习俗、食俗、养生、诗话、各地民俗 |
| `ui/screens/CheckInScreen.kt`    | 打卡：统计、月历、点亮进度、记录管理                   |
| `ui/screens/FolkMapScreen.kt`    | 民俗地图：地图、筛选、详情、投稿弹窗                   |
| `ui/screens/ProfileScreen.kt`    | 我的：昵称、提醒设置、主题、数据管理、关于             |
| `util/ShareUtils.kt`             | 系统分享封装                                           |

## 六、快速定位：课程考核点对应代码

| 考核点              | 所在位置                                                                                |
| ------------------- | --------------------------------------------------------------------------------------- |
| Activity 与生命周期 | `MainActivity.kt`                                                                     |
| 界面布局与控件      | `ui/screens/*`（Compose 声明式布局）                                                  |
| 列表展示            | `TermListScreen.kt`、`FolkMapScreen.kt`、`CheckInScreen.kt`（LazyColumn/LazyRow） |
| 页面跳转与传参      | `ui/navigation/Navigation.kt` + `MainActivity.kt` 的 `NavHost`                    |
| 数据存储（数据库）  | `data/db/*`（Room 三张表、增删改查）                                                  |
| 数据存储（键值对）  | `data/SettingsStore.kt`（DataStore）                                                  |
| 网络与权限          | 无网络请求（离线设计）；权限见 `AndroidManifest.xml` 与 `MainActivity` 通知权限申请 |
| 通知 / 广播         | `notify/*`（AlarmManager + BroadcastReceiver + NotificationCompat）                   |
| 自定义 View / 绘图  | `ui/components/TermWheel.kt`、`FolkMapCanvas.kt`（Compose Canvas）                  |
| 多线程 / 异步       | Kotlin Coroutines + Flow（仓库层与 UI 层）                                              |
| 单元测试            | `app/src/test/.../`（14 个用例全部通过）                                              |
| 分享 / 调用系统能力 | `util/ShareUtils.kt`                                                                  |
